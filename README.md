## Manually Triggering GitHub Actions Workflow

To manually trigger the GitHub Actions workflow from the GitHub UI, follow these steps:

1. Go to the "Actions" tab in your GitHub repository.
2. Select the workflow you want to run from the list of workflows.
3. Click on the "Run workflow" button.
4. Fill in any required inputs and click the "Run workflow" button again to start the workflow.

## Required Permissions

To run the GitHub Actions workflow, you need to have the necessary permissions. Make sure you have the appropriate access rights to trigger the workflow.
